# 债基再平衡助手

一个面向人民币债券基金组合的轻量级再平衡计算工具。

根据当前持仓、资金变动、目标比例和再平衡阈值，生成尽量减少换手的调整建议。

## 再平衡原则

- 采用 5/25 再平衡规则
- 越界后默认只拉回部分偏差
- 优先使用新增或取出资金纠偏
- 必要时才进行基金之间转换
- 支持在途交易和赎回限制
- 尽量减少不必要的换手

## 使用方法

1. 填写四只基金当前持仓
2. 如有新增或取出资金，填写资金变动
3. 点击“生成建议”
4. 根据执行清单操作

## 当前版本：v1.2.1

v1.2.1 是工程质量补丁，统一版本标记、README 与自动化测试配置，不改变产品行为、核心再平衡算法或无状态设计。

### v1.2.0 主要体验改进

- 输入时即时显示当前比例、目标偏离和是否越界
- “生成建议”为主操作，“强制回到目标”为次级操作
- 对比调整前、目标与调整后比例，用户可见百分比统一显示 2 位小数
- 执行摘要区分外部资金与内部转换，并支持一键复制执行方案
- 手机端四项持仓填写完整后才启用 sticky 操作栏
- 手机端结果按“执行摘要 → 执行清单 → 比例对比 → 计算说明”展示
- 手机端未生成建议时使用统一空状态，减少重复占位内容
- 支持清空本次输入和恢复默认参数
- 提供 PWA 安装入口与 iOS 添加到主屏幕指引

## 测试与稳定性

- 核心再平衡算法行为继续以 v1.0.1 稳定基线为保护对象
- Playwright 回归覆盖黄金用例、阈值边界、资金流、强制回目标、在途交易、赎回策略、取整、不变量、PWA 刷新、复制降级与 v1.2.0 UI 行为
- GitHub Actions 在分支推送和 Pull Request 阶段运行完整回归测试

## PWA

支持安装为 PWA，并支持离线使用。支持的浏览器可直接点击“安装应用”；iPhone 和 iPad 会显示“添加到主屏幕”的操作指引。

如已安装的 PWA 仍停留在旧版本，可点击页面底部的“刷新版本”，主动检查并加载最新版。

## 隐私

本工具采用纯前端计算。

- 不上传持仓数据
- 不需要登录
- 不保存个人资产信息
- 不进行云端同步

所有计算均在当前浏览器完成。

## Disclaimer

本工具仅用于个人资产配置计算，不构成投资建议。
