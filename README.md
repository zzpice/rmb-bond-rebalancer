# 债基再平衡助手

一个面向人民币债券基金组合的轻量级再平衡计算工具。

根据当前持仓、资金变动、目标比例和再平衡阈值，生成尽量减少换手的调整建议。

## 再平衡原则

- 采用 5/25 再平衡规则
- 越界后默认只回调部分偏差
- 优先使用新增或取出资金纠偏
- 必要时才进行基金间转换
- 支持在途交易和卖出策略
- 尽量减少不必要的换手

## 使用方法

1. 录入四只基金当前持仓
2. 如有新增或取出资金，录入本次资金变动
3. 点击“生成建议”
4. 根据执行清单操作

## PWA

支持安装为 PWA，并支持离线使用。支持的浏览器可直接点击“安装应用”；iPhone 和 iPad 会显示“添加到主屏幕”的操作指引。

如已安装的 PWA 仍停留在旧版本，可点击页面底部的“刷新版本”，主动检查并加载最新版。

## 隐私

本工具采用纯前端计算。

- 不上传持仓数据
- 不需要登录
- 不保存个人资产信息
- 不进行云端同步

所有计算均在当前浏览器完成。

## Disclaimer

本工具仅用于个人资产配置计算，不构成投资建议。
