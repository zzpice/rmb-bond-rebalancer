# 债基再平衡助手

一个面向人民币债券基金组合的轻量级再平衡工具，根据当前持仓、资金变动和目标比例生成调整建议，并尽量减少不必要的换手。

👉 [在线使用](https://zzpice.github.io/rmb-bond-rebalancer/)

## 再平衡原则

- 采用 5/25 再平衡规则
- 优先使用新增或取出资金纠偏
- 必要时才进行基金间转换
- 支持在途交易和卖出策略
- 尽量减少不必要的换手

## 使用

1. 填写四只基金当前持仓
2. 如有新增或取出资金，填写资金变动
3. 点击“生成建议”
4. 按执行清单操作

支持 PWA 安装和离线使用；桌面端提供单页侧栏导航，移动端提供顶部任务 tab，并可选择跟随系统、浅色或深色外观。

## 隐私

持仓与计算数据均在浏览器本地完成，不上传、不保存、不需要登录；仅外观偏好可保存在本机。
